# TEAM-WACK
# NO-Wait Customer support bot

A simple customer support bot for local shops that answers questions
only from shop‑provided FAQ data.

---

## 🧠 Idea
- Small shops receive the same questions daily (timings, pricing, parking).
- This app allows shop owners to paste their FAQ once and lets customers
ask questions through a chat interface.

- The bot answers **only from the given FAQ** and avoids incorrect answers.
